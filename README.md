# XiaoHeFarm
中期实训小河农场项目
一个集成了chatGpt3.5的unity项目，以下是使用说明：

#游戏介绍：
小河农场是一款模拟经营和休闲农场游戏，玩家可以根据自己的喜好管理自己的农场。农场有向日葵和苹果等作物，每种作物都有不同的生长时间和经济价值。通过浇水和施肥，可以影响这些作物的生长。

游戏设有六种不同的天气条件：沙尘暴、小雨、大雨、雪、高温和普通天气。游戏的早期阶段天气是固定的，后期则变为随机。

#快速入门指南：
- 金币和时间显示在左上角。
- 金币是游戏中玩家的私有财产。玩家开始时有500金币，可以用它们种植作物，并通过销售作物赚取更多金币。
- 小河农场中的时间是自动流逝的。随着时间的流逝，作物会自然生长。玩家可以通过浇水和施肥加速作物的生长。

#建造、任务和聊天位于右侧。
- 玩家可以点击“建造”按钮来建造商店和仓库等建筑。
- 玩家可以通过点击“任务”按钮查看当前的任务。
- 玩家可以通过点击“聊天”按钮与游戏中的AI角色聊天。

#游戏流程：
小河农场没有固定的游戏流程，一切都根据玩家的喜好进行。游戏提供了任务面板，玩家可以选择是否完成任务。

玩家可以在商店中选择他们想要种植的作物（向日葵和苹果），然后等待它们成熟。当作物成熟时，它们会显示一个收获图标。玩家可以点击这个图标来收获作物。收获的作物将被存储在仓库中，然后玩家可以出售它们。

#游戏特色：
小河农场的聊天功能基于人工智能，为玩家提供了真实的交流体验。
